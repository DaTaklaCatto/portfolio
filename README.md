## ✨ Features

- **Theme Switcher:** Sleek dark-first visual styling with full dynamic light/dark theme toggling.
- **Lenis Smooth Scroll:** Hardware-accelerated smooth scrolling integrated seamlessly with anchor links.
- **GSAP Animations:** Scroll-triggered element reveals, text split animations, and dynamic hero section entrances.
- **Interactive UI:** Preloader sequence, mobile drawer navigation, magnetic hover effects, and one-click email copying.
- **SEO & Social Optimization:** Complete Open Graph, Twitter Cards, and JSON-LD Person Structured Data for search engines.

## 🛠️ Built With

- **HTML5 & CSS3** — Native CSS Custom Properties (Variables) & modern layout modules (Grid/Flexbox)
- **JavaScript (ES6+)** — Pure asynchronous JS
- **[Lenis](https://lenis.darkroom.engineering/)** — Smooth scroll engine
- **[GSAP](https://gsap.com/)** — Animation library (ScrollTrigger, ScrollToPlugin, CustomEase)
- **[Lucide Icons](https://lucide.dev/)** — Clean vector icon set
- **Google Fonts** — _Inter_ & _JetBrains Mono_

## 🚀 Getting Started

Local Development
No heavy framework or build tools are required. You can serve the site locally using any static server:

### 1. Clone the repository:

```code
git clone [https://github.com/DaTaklaCatto/portfolio.git](https://github.com/DaTaklaCatto/portfolio.git)
cd portfolio
```

### 2. Serve locally:

- Using Live Server extension in VS Code, or:

- Using Node.js http-server:
  ```code
  npx http-server .
  ```
- Open http://localhost:8080 in your browser.
